## 关键发现

### 1. 年限过滤 bug 已修复（本次修复）

原 `core/ns_parser.filter_records` 以 `dt.date.today()` 为基准，导致 2016-2020 年老比赛
的 recent/h2h 全部被"距今 5 年"过滤清空。已改为**以本场比赛开赛年份为基准**、
按年份过滤（`reference.year - H2H_YEARS`）。修复后：

- 2016-01 sid=1130409：h2h 0→3，rh 25，ra 23（原页面 30/30，黑名单+年份过滤后合理）
- 2016-04 sid=1130485：h2h 11，rh 30，ra 30
- 老比赛 recent/h2h 全部恢复正常

### 2. h2h 偶发为 0 = 真实无交锋，非 bug

- 2026-08 欧冠首回合 sid=3049291：h2h 0（两队首次交锋，页面 v_data 本来就空）
- 2020-10/11、2024-07 等若干场次 h2h 0，均为首回合/杯赛首轮，页面无数据
- 有交锋记录的场次 h2h 1~20 条不等，解析正常

### 3. media 解析选择器修复（本次修复）

原 `ns_parser._extract_comtable_block` 只匹配 `媒体分析` 标题 + `class="fx_title2"`，
导致老页面（标题"心水推荐"、容器 `porlet_xs`、无 class h3）全部解析不到 → media 大面积为空。

已改为 `_extract_media_block`：
- **优先按容器 id 定位**：`porlet_18`（近年主流）→ `porlet_xs`（老页面），标题校验
- **无 id 布局 table 兜底**（老页面 width=940），按标题"心水/媒体分析"锚定
- **匹配兼容繁简体 + 同字异码点**：走势/走勢、盘路/盤路、赢输/贏輸、指数/指數 等
- **urllib 快取兜底**：处理 UTF-8 BOM / GBK，解决 playwright 对大页面间歇抓取失败

修复后 media（trend/conf/analysis）命中 124/126（98%），仅 2 场小赛事页面真缺失。

### 4. standings 缺失 = 页面无积分榜，非解析 bug

`core.parser.parse_standings` 依赖 `[联赛名N]队名</b>` 括号式标题定位积分榜表格。
抽样缺失的 48 场（多为 2016-2020 的小联赛/杯赛/预选赛），经核实：

- 页面**确实无积分榜区块**（"积分"关键词仅出现在广告位 Ad1 等无关文本）
- 主流联赛（英超/西甲/德甲/瑞典超等）积分榜解析全部成功
- sid=1124597（西甲预选）失败、sid=1232737（瑞典超）成功，已对比验证
